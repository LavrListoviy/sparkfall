# Графика первого прототипа

## Печной автомат

- Файл в проекте: `public/assets/furnace-automaton.png`.
- Создан встроенным инструментом ImageGen, без внешнего API-ключа.
- Иллюстрация проверена визуально и скопирована в проект; приложение не зависит от служебной папки генератора.
- Символы фишек и интерфейса написаны отдельно в SVG в `public/icons.js`; сама иллюстрация не используется как интерактивное поле.

Style: polished hand-painted indie fantasy game art, graphic bold shapes, textured brushwork, evocative illustrated storybook, sophisticated limited palette, strong silhouette, charming but threatening, no photorealism, no 3D plastic. Composition: central full figure occupying 70% frame, low perspective, visible feet, dramatic rim light, dark navy smoky surroundings, corners nearly black so it integrates in a dark game panel.
