# Итерация 4 — публикация и обратная связь

## Подтверждённый объём

Пользователь запросил запуск в локальной сети, публичный GitHub-репозиторий, GitHub Pages, форму отзывов с доставкой в отдельный ярлык Gmail, скриншоты и короткое видео в README. Это разрешает создание репозитория, коммитов и публикацию этой итерации. Новые игровые механики в этот выпуск не входят.

## P01 — переносимые пути и публикация

- Ресурсы HTML/CSS и загрузчик Three.js работают из корня и подпапки `/sparkfall/`.
- GitHub Actions запускает тесты и публикует только `public/` через GitHub Pages. Документы, тесты и локальные файлы в сайт не попадают.
- Временный рекордер `public/_dev/` исключается из Git и переносимых сборок.
- Публичный репозиторий исключает `node_modules`, локальные архивы, ключи, временные файлы, личные пути и черновые записи.
- Автор коммитов использует GitHub noreply; почтовый адрес для отзывов не публикуется в исходниках.
- Начатые забеги и версия игровых правил 0.5.0 не меняются из-за публикации. Профиль остаётся привязан к origin.

## F01 — форма отзыва

Подтверждено пользователем: FormSubmit → Gmail, скрытый идентификатор формы, ярлык `Sparkfall / Feedback`. Получатель согласован в чате; личный адрес не публикуется в репозитории.

- Кнопка «Оставить отзыв» доступна из мастерской, карты, боя и результата. Во время показа хода открытие формы недоступно.
- Поля: категория (впечатление/ошибка/идея), текст 10–4000 символов, необязательный email для ответа. Текст отзыва не подставляется в HTML.
- По умолчанию никакой журнал не отправляется. Явный флажок разрешает приложить воспроизводимый отчёт о текущем забеге; до отправки можно увидеть его состав.
- Перед отправкой объяснить, что текст, выбранный email и необязательный отчёт передаются через почтовый сервис автору игры. Не собирать устройство, IP, профиль или историю скрытой аналитикой.
- Валидировать текст/email, ограничить размер вложенного отчёта, не отправлять повторно при двойном нажатии. Успех показывать только при подтверждённом принятии сервисом; это не подтверждение доставки в Gmail.
- Сетевая ошибка, отказ или неактивная форма сохраняют введённый текст и дают явное сообщение. Не делать автоматических повторов, способных дублировать письмо.
- Тема письма содержит `[Sparkfall Feedback]` для фильтра Gmail. Фильтр присваивает отдельный ярлык и убирает письмо из входящих, сохраняя его.
- FormSubmit требует активации адресов сайта отдельно: подтвердить публичный сайт и текущие локальные адреса письмом владельцу. Новый IP может потребовать новой активации; не выдавать отказ сервиса за успешную отправку.
- Секреты Gmail/API в браузере и публичном репозитории отсутствуют. Ярлык не считается работающей автоматической сортировкой без фильтра.

## P02 — локальная сеть

Запущен отдельный сервер на TCP 4175, без остановки прежнего локального 4173. Разрешение брандмауэра ограничено Node, портом 4175, частным профилем и локальной подсетью. Если Windows требует администратора, сообщить и дать конкретную команду; не отключать брандмауэр целиком.
