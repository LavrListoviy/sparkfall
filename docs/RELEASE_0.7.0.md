# Искропад 0.7.0 — мастерская артефактов

15 ноября 2026 года.

Новые предметы можно собирать в локальном редакторе из готовых событий, условий и эффектов, сохранять в проект и сразу проверять на игровом ядре. Для работы с Codex добавлены два проектных навыка. Исходные 21 артефакт и их баланс сохранены.

[Играть в браузере](https://lavrlistoviy.github.io/sparkfall/).

## Редактор и конструктор

- Создание, копирование, поиск и отключение предметов; название и описание RU/EN, иконка, цвет, редкость и цена чертежа.
- До 16 правил на предмет: после группы, перед дополнительной каскадной волной или после раунда и шторма.
- Условия по типу и размеру группы, положению относительно шторма, яду и ознобу на исходной цели.
- Эффекты: урон выбранной стихией, яд, озноб, лечение и метеоритный щит. Цель — текущий враг, первый другой живой или все живые; лечение и щит относятся к герою.
- Ограничение срабатывания: каждое событие либо один раз за действие, раунд или бой. Можно сочетать правила с существующей специальной базовой механикой.
- Бонусы частот глифов, предпросмотр RU/EN и стенд с реальным расчётом HP, статусов и боевых событий.
- Черновик в браузере, импорт/экспорт JSON, проверка данных перед записью и защита от перезаписи изменений другой вкладки.

Редактор запускается из исходников проекта, нужен Node.js 22+:

```powershell
npm.cmd run editor
```

Открыть `http://127.0.0.1:4174/`. Создать предмет → собрать эффекты → проверить на стенде → сохранить в проект. Затем обновить страницу игры и начать новую экспедицию. После изменения контента выполнить `npm.cmd run glossary` и `npm.cmd test`.

Каталог сохраняется в `public/core/artifact-catalog.js`. Сервер редактора слушает только локальный адрес; его интерфейс и API записи не входят в опубликованную игру и игровые архивы. Для редактора скачай **Source code (zip)** со страницы релиза либо используй репозиторий. Установка пакетов для запуска не требуется.

## Проектные навыки Codex

- **`$sparkfall-create-artifact`** — создать или настроить предмет из готовых возможностей: данные, RU/EN, условия, лимиты, тесты и проверка в игре.
- **`$sparkfall-extend-artifact-effects`** — добавить недостающую механику в ядро и конструктор через спецификацию и TDD, с проверкой старых сохранений и реплеев.

Навыки находятся в `.agents/skills/` исходников. Вызвать можно по имени в запросе внутри проекта. Инструкции ссылаются на текущую схему и код, а не на отдельную копию правил.

## Сохранения и обновление

Каждая новая экспедиция фиксирует собственный каталог, включая эффекты, тексты, цены и частоты. Изменение предмета в редакторе не переписывает уже начатый забег и его отчёт. Новые определения применяются после обновления игры к новой экспедиции.

Сохранения и отчёты версий 0.3–0.6 поддерживаются через исторический каталог. Профиль и разблокировки сохраняются. Для сохранения браузерного профиля оставайся на прежнем адресе: GitHub Pages, `localhost`, `127.0.0.1` и разные порты имеют отдельные хранилища.

## Скачать игру

- **`sparkfall-0.7.0-playtest.zip`** — распаковать, запустить `start-game.cmd`, открыть `http://localhost:4173/`. Нужны Node.js 22+ и браузер с WebGL 2. На других системах — `npm start`.
- **`sparkfall-0.7.0-web.zip`** — статические файлы для HTTP-хостинга, в том числе в подпапке. Запуск через `file://` не поддерживается.
- **`SHA256SUMS.txt`** — контрольные суммы двух игровых архивов.
- **Source code** — полный проект с редактором, тестами, документацией и навыками.

## Проверки и ограничения

- **156/156 автоматических тестов**: прежние игровые правила и реплеи, структура каталога, порядок и лимиты эффектов, снимки сохранений, локальный API и защита от конфликта записей. Глоссарий синхронизирован.
- Редактор проверен в браузере на 1440×900 и 390×844: создание и копирование, RU/EN, стенд, запись в проект, черновик, импорт/экспорт, конфликт вкладок и появление предмета в игре.
- Оба навыка прошли валидатор; проверены метаданные, 39 ссылок и пример правила на настоящем игровом ядре.

Стенд проверяет срабатывание правил, но не доказывает баланс полного забега. Внутренние числа специальных базовых блоков пока фиксированы. Физический телефон, масштаб 200% и настоящий экранный диктор остаются отдельными проверками; автоматический выбор навыков приложением отдельно не проверен.

Практические сценарии QA: две группы в одном действии не обходят лимит; неверное значение не сохраняется; погибшая цель не перенаправляет эффект; правка каталога не меняет старый забег; устаревшая вкладка получает конфликт вместо тихой перезаписи.
